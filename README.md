1)Процент — fee = sum * rate
Пример: 1000, 2% → 20

2)Фиксированная — fee = fixed
Пример: sum любой, fixed=15 → 15

3)Смешанная (процент + фикс) — fee = sum * rate + fixed
Пример: 2000, 1% + 10 → 30

4)Ступенчатая по диапазонам
-Одна ставка по диапазону (single-tier) — выбирается диапазон по сумме и ставка применяется ко всей сумме:
Пример: 0–1000=2%, 1000–5000=1.5%; sum=4000 → 4000*1.5% = 60
-Прогрессивная — каждый диапазон применяется только к своей части суммы:
Пример: 0–1000=2%, 1000–5000=1.5%, 5000+=1%; sum=6000 → 20 + 60 + 10 = 90

6)Минимум/максимум (ограничения) — fee = clamp(fee, min, max)
Пример min=10: 1% от 200=2 → 10; max=50: 1% от 10000=100 → 50
