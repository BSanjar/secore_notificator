# Тест отправки по почте

## Что нужно для теста

### 1. Заполнить SMTP в `appsettings.json`

В секции **NotificationSettings:Email** укажите:

| Параметр      | Пример              | Описание |
|---------------|---------------------|----------|
| **SmtpHost**  | `smtp.gmail.com`    | Уже задан по умолчанию |
| **SmtpPort**  | `587`               | Обычно 587 (TLS) |
| **SmtpUser**  | ваш email           | Логин (полный email для Gmail) |
| **SmtpPassword** | пароль приложения | Пароль SMTP (для Gmail — не пароль входа, а «Пароль приложения») |
| **FromEmail** | тот же или другой   | С какого адреса показывать письмо (можно оставить пустым — подставится SmtpUser) |

**Gmail:** зайдите в аккаунт Google → Безопасность → Двухэтапная аутентификация (должна быть включена) → Пароли приложений → создайте пароль для «Почта» и укажите его в **SmtpPassword**.

**Другие почты (Яндекс, Mail.ru, корпоративная):** в справке сервиса найдите SMTP-сервер, порт и настройки (обычно «разрешить доступ по SMTP» и пароль приложения или основной пароль).

### 2. Включить тест при старте

В **appsettings.json** в секции **TestOnStartup:Email**:

- **Enabled**: `true`
- **To**: ваш email, на который должно прийти тестовое письмо (например `your@email.com`)

### 3. Запустить воркер

```bash
dotnet run
```

При старте отправится одно тестовое письмо с темой «Тест SECORE — рассылка». В логах будет сообщение об успехе или ошибке SMTP.

---

## Тест через таблицу notifications

Можно не использовать тест при старте, а вставить запись в БД:

- **channel**: `email`
- **contact_info**: адрес получателя (один email)
- **subject**: тема
- **message**: текст (можно HTML)
- **status**: `new`

Воркер подхватит запись и отправит письмо (проверка каждые 10 секунд).
